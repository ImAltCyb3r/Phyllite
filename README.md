# Phyllite

## Phyllite

Phyllite is a Geometry Dash creation and exploration project designed to expand the tools available to creators and players.

## Explorer

Explorer is Phyllite's content browsing environment.

It provides access to levels, level lists, maps, plugins, and other available content.

## Editor

Editor is Phyllite's broader creation environment.

It includes the Level Editor along with Phyllite-specific creation tools and features.

## Map

Map is a concept for a map-based way of navigating Phyllite content.

Maps use the `.gmap` file format and reference existing Geometry Dash levels or level lists.

## Versus

Versus is a concept for a multiplayer-focused system within Phyllite.

## Plugins

Phyllite supports plugins through the `.phle` file format.

Plugins can add editor functionality, tools, interfaces, triggers, and other Phyllite-compatible features.

## File Formats

### `.gmap`

Phyllite Game Map files.

A `.gmap` can reference either individual level IDs or a level list ID.

### `.phle`

Phyllite Plugin files.

A `.phle` packages a plugin and its required files and resources.

## Error Handling

Phyllite uses Geometry Dash-style `FLAlertLayer` dialogs for displaying errors.

Errors use unique codes to make them easier to identify and troubleshoot.

## Project Goal

Phyllite aims to combine creation, exploration, customization, maps, plugins, and multiplayer concepts into one Geometry Dash-focused project.

Phyllite is not intended to be a traditional mod menu or a collection of unfair gameplay modifications.

## Status

Phyllite is currently in development. Map and Versus are currently concepts and may change during development.
