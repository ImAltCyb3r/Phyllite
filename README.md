# Phyllite

A Geometry Dash mod platform built exclusively for iOS.

Phyllite is an iOS-only project focused on making Geometry Dash mods, tools, and fangames easier to install, organize, and launch.

Features

iOS-first — Designed specifically for iPhone and iPad.
   Mod management — Install and manage Geometry Dash mods.
  Phyllite Home — A central Home Screen for installed content.
    Fangame support — Fangames can appear as launchable entries on the Home Screen.
   Storage monitoring — Keep an eye on how much space your mods are using.
   Mod types — Content can identify itself as a Mod, Fangame, Tool, etc.

Project Status

Currently in development.

Phyllite is still being designed, so features and implementation details may change.

Platform

Supported: iOS / iPadOS
Not supported: Windows, macOS, Linux, Android
